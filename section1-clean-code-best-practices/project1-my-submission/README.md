# <center> Predict Customer Churn with best coding practices

- Project **Predict Customer Churn** of ML DevOps Engineer Nanodegree Udacity

## Project Description

Which customers are most likely to churn? This is the question that this project answers.We used credit card dataset for this Machine Learning classification task. The python code follows clean code principles (PEP8) and software engineering best practices.

## Files and data description

* ***churn_library.py***: This python file is a library of functions that we used to find customers who are likely to churn.

* ***churn_script_logging_and_tests.py***: This python file:

        * Contains unit tests for the *churn_library.py* functions;

        * Log and INFO messages of any errors in a .log file

* ***README.md***: In this file, we provide an overview of the project and the instructions to use the code

## Running Files

install dependencies with this command : pip install -r requirements.txt

I run this project in Python 3.10.1 version.
